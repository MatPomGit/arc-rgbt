# E02: temporal skew and geometric overlap

Analytical, simulated 84-case sweep of timing mismatch and idealized
lateral rectangle overlap. At a fixed field of view, normalized
geometric IoU is resolution-independent in this model; it is **not**
a detector accuracy metric.

```bash
arc-rgbt-e02 --config experiments/E02/config.json --output reports/E02
```

Canonical assumptions, formulas, output schema and limitations:
[E02 guide](https://github.com/MatPomGit/arc-rgbt/blob/main/docs/experiments/e02.md).
