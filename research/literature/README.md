# Literature queue

Use the [curated DOI screening](../../docs/experiments/literature-screening.md)
for the current selection and status of bibliographic verification.
Original survey documents and the full imported export are **not**
committed here.

Future additions must have identity/source provenance, modality,
dataset licence, native resolution, split policy and a clear distinction
between author-reported claims and replicated evidence.
See [measurement rules](../../docs/guides/evaluation-requirements.md).
