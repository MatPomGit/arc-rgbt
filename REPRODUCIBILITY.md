# Reproducibility

The canonical protocol is [Reproducibility and quality assurance](docs/reproducibility.md).
It covers exact source SHAs, environment and input provenance, offline
validation, independent study units, interpretation of E00–E02 and
pre-publication evidence. For detailed performance reporting see
[Measurement and evaluation requirements](docs/guides/evaluation-requirements.md).

This entry point is retained for existing research-workflow references.
