# E00: native thermal-resolution sweep

**E00** evaluates the behaviour of a class-agnostic threshold localization baseline under deterministic simulated resolution and noise conditions. It does not train or evaluate a physical person/vehicle recognizer.

## Design

- Source: 20 seeded 320 × 240 simulated scenes, each with two labelled geometric rectangles and background noise.
- Seven output grids: **8×8, 16×12, 32×24, 80×60, 160×120, 256×192, 320×240**.
- Fixed configuration in `experiments/E00/config.yaml`; seeded per-frame noise.
- Native processing uses the configured spatial resolution; enlarged PNG previews are for viewing only.
- Ground-truth boxes are rounded outward to native pixel cells for the detection evaluation.
- Geometric diagnostics `median_unrounded_bbox_area_native_px2` and `fraction_objects_subpixel_axis` use **unrounded** native pixel footprints; one-pixel outward annotation rounding is not evidence that the sensor resolves a target.

## Reproduce

```bash
arc-rgbt-e00 --config experiments/E00/config.yaml --output reports/E00
python publications/P01/analyses/summarize_e00.py \
  --experiment-dir reports/E00 \
  --output reports/P01/e00_summary.json
```

These files are generated under `reports/E00/`:

| Artifact | Contents |
| --- | --- |
| `manifest.json` | Configuration, per-resolution metrics, data origin, observability and provenance |
| `metrics.csv` | Comparable numeric metrics across resolutions |
| `report.html` | Local human-readable table with explicit simulation warning |
| `preview_*x*.png` | Nearest-neighbour visualization only |
| `reports/P01/e00_summary.json` | Independently derived tabulation and SHA-256 of source artifacts |

The analysis rejects manifest/CSV disagreements on evaluation and geometric fields. It does not validate the real-world accuracy of simulated values.

## Pre-publication checklist

1. Freeze the exact Git commit and dependency environment.
2. Preserve configuration, seed, input model and output digests.
3. State that class-agnostic connected components **do not** classify person or vehicle labels.
4. Report both unrounded footprints and rounded evaluation annotations.
5. Avoid statistical claims about real cameras from synthetic-only observations.
