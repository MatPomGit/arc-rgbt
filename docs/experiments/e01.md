# E01: quality-weighted detection fusion

E01 is a **synthetic, labelled software experiment**, not a field validation.
It compares four late-detection methods on the **same** precomputed proposals
and ground-truth annotations. No camera driver, neural detector, learned
reliability estimator or temporal tracker runs in E01.

## Study arms

| Arm | Behaviour |
| --- | --- |
| `rgb_only` | RGB proposals at the common score gate |
| `thermal_only` | Thermal proposals at the same gate |
| `fixed_fusion` | Greedy class-aware IoU fusion with unit modality qualities |
| `quality_aware_fusion` | Same fusion with externally specified RGB and thermal quality factors |

For `quality_aware_fusion`, effective score = original score × declared
modality quality. Boxes below `min_effective_score` are discarded.
Matched boxes are coordinate-averaged using these scores; the output
confidence is not calibrated. The IoU threshold serves **both**
matching the proposals across modalities and evaluating predictions
against ground truth, as currently configured by the E01 implementation.

## Reproduce from the repository root

```bash
arc-rgbt-e01 --dataset datasets/manifests/e01-synthetic-quality.json \
  --output reports/E01
```

The checked-in input is deliberately constructed to demonstrate how the
heuristic responds to alternative modality weights. The declared
`quality_origin: synthetic_scenario` is not derived from an independent
quality estimator. The output directory contains:

- `manifest.json`: run configuration, per-method metrics, data provenance
  and interpretation limits.
- `metrics.csv`: four method rows with TP, FP, FN, precision, recall,
  F1, IoU threshold and number of frames.

For the full input schema see [data contracts](../reference/data-contracts.md)
and for the algorithm see [quality-aware fusion](../guides/quality-fusion.md).

## What the experiment cannot demonstrate

An increase in F1 on this hand-authored dataset is **not** evidence of
better physical person/vehicle detection. E01 does not compute average
precision, rank-confidence calibration, performance uncertainty or an
operating-point sweep. A common score threshold is **not** necessarily
a matched false-alarm budget between methods.

For an empirical P02 comparison, independently define the scene-level
train/validation/test split, calibrate the detector confidence and
independently estimate quality without peeking at test labels.
Freeze thresholds before evaluation and quantify uncertainty by
independent acquisition sequence. See the [P02 study plan](publications.md).
