# E02: temporal-skew geometry

E02 is an analytical simulation of temporal pairing and lateral target
motion. It provides a **geometric sensitivity diagnostic**, not
detector accuracy, physical thermal resolution or sensor performance.

## Reproduce

```bash
arc-rgbt-e02 --config experiments/E02/config.json --output reports/E02
```

The committed scenario varies:

| Factor | Levels |
| --- | --- |
| Thermal grid | 8×8, 16×12, 32×24, 80×60, 160×120, 256×192, 320×240 |
| Thermal start offset | 0, 10, 25, 50 ms |
| Target lateral speed | 0, 3, 6 m/s |
| RGB and thermal capture rate | 30 fps and 9 fps |
| Temporal acceptance tolerance | 25 ms |

It produces **84 rows** (7 × 4 × 3) in `geometry.csv` plus
`manifest.json` with the simulation origin, timing summaries,
model assumptions, exact configuration and provenance.

## Model and units

The reference uses a simulated shared monotonic clock and
`pair_frames` to associate thermal and RGB timestamps. For
native thermal width (W) pixels, horizontal FOV (alpha), range
(D) metres, physical target width (L) metres, lateral speed
(v) metres/second and absolute paired skew (Delta t) seconds:

```text
focal_px  = W / (2 * tan(FOV / 2))
width_px  = L * focal_px / D
shift_px  = v * abs(skew_seconds) * focal_px / D
bbox_IoU  = max(0, (width_px - shift_px) / (width_px + shift_px))
```

The output `median_geometric_bbox_iou` is the median overlap
of **two ideal axis-aligned rectangles**, not a measured detection
IoU. Unpaired captures produce `null` overlap summaries rather than
fabricated detections.

!!! warning "Fixed-FOV cancellation"
    When FOV, distance and physical target width stay fixed, the
    simulated width and shift both scale with native pixel width.
    Their *normalised overlap is independent of resolution*.
    This model cannot establish detection superiority of any thermal
    resolution, account for sensor MTF/PSF/NETD or simulate missing
    native image information.

## Limitations and next study

The model assumes an ideal pinhole lens, frontal rectangles and
lateral motion at constant range. It does not include projective parallax,
clock drift calibration, sensor contrast, occlusion, rolling shutter,
camera jitter or actual model inference. Its `data_origin` is
`simulated`, `metric_origin` is `analytical_geometry`, and
`physical_measurements` is `false`.

For a real P02 acquisition, measure exposure timestamps and calibrated
geometry, preserve physical native grids, evaluate labelled scene
sequences independently and report detector outcomes separately from
this analytical proxy. Review [timing and registration](../guides/synchronization-registration.md)
and [evidence limits](../concepts/evidence.md).
