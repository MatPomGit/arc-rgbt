# Command-line tools

The authoritative command list, flags and Python API are in
[docs/reference/cli.md](../docs/reference/cli.md).

After `python -m pip install -e .`, use `arc-rgbt --help` for the
unified launcher or `<command> --help` for tool-specific options.
Scripts in `tools/` are compatibility wrappers around the
`src/arc_rgbt/` implementations.

For a working walkthrough see [Getting started](../docs/getting-started.md).
