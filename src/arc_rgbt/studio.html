How to interpret the images

Raster images use browser-decoded 8-bit sRGB intensities. NumPy inputs retain original dtype and min/max in the JSON export, but use independent min–max stretching for display. RGB is converted to grayscale using 0.2126 R + 0.7152 G + 0.0722 B without linear-light conversion; transparent pixels are composited over black. The blend and difference views are only visual diagnostics, not camera calibration, radiometry, spatial registration, a trained detector, a benchmark or a sensor performance measurement.
