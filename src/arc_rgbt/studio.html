2. Explore fusion

Interpretation limits. Input pixels are browser-decoded 8-bit sRGB values, not calibrated thermal radiance or temperature. Each RGB image is converted to grayscale using sRGB coefficients (0.2126 R + 0.7152 G + 0.0722 B) without linear-light conversion. The weighted output is a visualization, not a sensor calibration, trained detector, benchmark or radiometrically valid product. Transparency is composited against black. The difference view is an intensity diagnostic, not a registration-quality metric.
