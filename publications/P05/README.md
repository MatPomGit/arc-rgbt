# P05: Cross-Sensor Generalization of Low-Cost RGB–Thermal Detection

**Classification:** CORE — planned. **Date:** 2026-10-28.
This is a proposed publication, not a completed manuscript or a claim of empirical performance.

**Research question.** Can a bounded training-only adaptation reduce detection degradation on unseen physical RGB/LWIR sensors and acquisition environments?

**Independent contribution.** Resizing frames from one device does not establish cross-sensor transfer. P05 studies external validity, not P01 pixel-footprint or P02 fusion gain.
